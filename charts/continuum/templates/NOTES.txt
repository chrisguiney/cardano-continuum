continuum is starting in namespace {{ .Release.Namespace }}: the genesis Job
renders and publishes the devnet, the operator starts {{ include "continuum.totalPools" . }} pools, and
the engine waits for pool 0.

  kubectl -n {{ .Release.Namespace }} get continuumpools,pods
{{- if and .Values.engine.enabled .Values.ui.enabled }}

The UI is the {{ .Values.ui.service.type }} Service continuum-ui, which forwards /api to the
engine. Neither has authentication.

  kubectl -n {{ .Release.Namespace }} port-forward svc/continuum-ui {{ .Values.ui.port }}
  open http://127.0.0.1:{{ .Values.ui.port }}
{{- else if .Values.engine.enabled }}

The engine's API (no UI, no authentication) is the ClusterIP Service continuum-api:

  kubectl -n {{ .Release.Namespace }} port-forward svc/continuum-api {{ .Values.engine.api.port }}
{{- end }}
