# web/src/components/ui

shadcn/ui components, copied in as source so they can be read and changed
here: `alert-dialog`, `badge` (with `ok`, `warn` and `bad` variants),
`button`, `input`, `native-select`, `table` and `tooltip`. Each element
carries a `data-slot` attribute naming its part. To add one, see
[`web/README.md`](../../../README.md#adding-a-shadcnui-component).
