# web/src/views

`Explorer` (with `ExBlock`, `ExTx`, `ExAddress`, `ExEpoch`), `Governance`,
`GovAction`, `Decisions`, `Findings`, `Adversaries`, `Controls`, `Help`.
Shared pieces: `common.tsx`, `fields.tsx` (inputs and the `HelpTip`),
`filterbars.tsx`, `exparts.tsx`, `govparts.tsx`, `SearchBox.tsx`.
