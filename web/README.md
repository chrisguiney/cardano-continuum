# web

The single-page UI served by `continuum serve`: Preact, Vite and TypeScript.

- `web.go`: embeds `dist/` and serves it; paths without an extension fall back
  to `index.html` so client routes survive a reload.
- `index.html`, `vite.config.ts`, `tsconfig.json`, `package.json`: the build.
  `npm run dev` proxies `/api` to `127.0.0.1:8088`.
- [`src/`](src/README.md), [`public/`](public/README.md), [`test/`](test/README.md).
- `dist/` (and `dist/assets/`): build output, committed so `go build` needs no
  Node. Regenerated by `make web`; do not edit.

`make web` rebuilds `dist/`; `make web-test` typechecks and runs Vitest. Both
need Node and npm. See the repo [README](../README.md) for running the UI.
