# docs/screenshots

PNG screenshots of the web UI in [`web/`](../../web/README.md), one per view
or state: overview, actors and actor detail, pools, explorer (blocks, block,
transaction, address), governance (parameter change, treasury), decisions,
findings, adversaries, controls and help.

The `-sample` images (`decisions-sample.png`, `pools-sample.png`) use
stand-in API data: a fake run has no pools and writes its log only when it
ends.
