# lab/example

Output of `lab/fit.py` on a preview chain slice, committed as a reference:

- `profile.yaml`: the fitted profile (parses with `profile.Parse`).
- `target.json`: the quantiles and fractions `grade.py` checks a run against.
- `clustered.yaml`: a profile fitted with `--clusters`.

See [`lab/README.md`](../README.md) for how they are produced and used.
